# hackathon-1109

Материалы команды для КосмоХакатона 2026 (11–12 сентября). Выбран
**Кейс 02 «Космос как инфраструктура»**, команда из пяти человек (роли A–E).

## Структура

- `cases/case02/` — материалы организаторов Кейса 02: README, канонический расчёт
  `case_core.py`, данные и конфиг. Не редактируются.
- `cases/case01/` — материалы Кейса 01, сохранены как история выбора.
- `docs/team/` — общий график (`README.md`), личные инструкции A–E, вопросы организаторам.
- `docs/case02-team-plan.md` — план на пятерых: роли и критерии, кандидаты для гейта,
  структура сдачи и записки.
- `docs/mockup/` — макет расчётного инструмента «Космо-портфель»: пять экранов,
  варианты шрифтов, рендеры PNG.
- `docs/case-research.md` — сверка обоих кейсов с ТЗ до выбора; исторический документ.
- `tools/` — `case02_enumerate.py` (перебор всех портфелей Кейса 02),
  `case01_baseline.py` (базовые числа Кейса 01).
