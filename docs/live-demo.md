# Live-demo интерфейса: сценарий на 60–90 секунд

Показ идёт в `app/` (`python app/server.py` → http://127.0.0.1:8765). Восемь
шагов, четыре раздела, никаких лишних экранов. Числа ниже — из
`results/base.json`, `results/stress.json` и `results/ranking_full.csv`; на
экране они совпадают один в один (проверка `app/tests`, класс `CrossCheckKosmo`).

Перед показом: сервер запущен, сценарий в шапке — BASE, тема светлая, на
экране «Портфель · Обзор» подпись FINAL (если стоит «произвольный портфель»,
нажать «Вернуть FINAL»).

## Если что-то пошло не так

- Сервер не запущен → интерфейс открывается со статического файла
  `app/static/data/dashboard.json`: обзор, ограничения, «Почему FINAL» и
  стресс работают, конструктор считает только комбинации из файла и пишет
  об этом. Запустить `python app/server.py` и обновить страницу.
- В шапке стоит STRESS с прошлого показа → выбрать BASE до шага 1.
- Показан не FINAL → «Вернуть FINAL» на любой вкладке портфеля.
- Нужно другое нарушение → в конструкторе взять FIRE-A, FLOOD-A, TRANS-A, ENV-A
  (V3): c0 1 249.5 > 1 180, превышение 69.5 млн руб.; BASE при этом PASS.
- Тёмная тема для проектора — переключатель в шапке рядом со сценарием.
