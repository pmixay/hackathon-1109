# Макет инструмента «Космо-портфель»

Статичный макет пяти экранов расчётного инструмента для Кейса 02: ориентир
для роли A (что собирать) и роли E (скриншоты для слайдов). Цифры на экранах
взяты из перебора `tools/case02_enumerate.py` и кандидатов V1–V5 из
`docs/case02-team-plan.md` §4.

## Файлы

- `kosmo-portfolio.html` — пять экранов в одном файле: Портфель, Сравнение,
  Стресс, Отсев, Допущения. Открывается в браузере; шрифты подгружаются с Google Fonts.
- `fonts.html` — экран «Портфель» в трёх вариантах шрифтов. Это предложение:
  после выбора пары файл удалить.
- `renders/` — PNG каждого экрана (1440 px, 2x) и `fonts.png` со сравнением шрифтов.
- `render.mjs` — скрипт рендера (Playwright + Chromium).
- `logo.png` — логотип команды; в макет вшита уменьшенная копия.

## Принципы редизайна

- Одна светлая шапка с вкладками и переключателем BASE/STRESS; тёмной боковой
  панели нет.
- Плитка = показатель, порог, запас и галочка статуса; отдельной таблицы
  ограничений нет. Четыре условия состава — одной строкой под плитками.
- Текст только там, где он несёт число, порог или статус: без пояснительных
  абзацев, легенд «использовано/запас» и сносок.
- Зелёный бренда (из логотипа) только для статуса, активной вкладки и главной
  кнопки; статусы — зелёный, жёлтый, красный.

## Шрифты

Выбрано: **Golos Text** (текст и интерфейс) + **Manrope** (заголовки и крупные
цифры). Альтернативы в `fonts.html` и `renders/fonts.png`: **Onest** (одна
семья на всё) и **Geologica + JetBrains Mono** (инженерный тон, моноширинные
цифры). Все три есть на Google Fonts с кириллицей; в Streamlit подключаются
одной ссылкой `<link>` через `st.markdown`.

## Как перерендерить

```
npm i -g playwright && npx playwright install chromium   # один раз
node docs/mockup/render.mjs docs/mockup/kosmo-portfolio.html docs/mockup/renders
node docs/mockup/render.mjs docs/mockup/fonts.html docs/mockup/renders --fullpage fonts
```

Без доступа к Google Fonts можно задать `FONT_DIR` — папку с `local-fonts.css`
(CSS Google Fonts с путями `./*.woff2`) и файлами шрифтов.
