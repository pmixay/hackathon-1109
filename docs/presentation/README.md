# Презентация защиты

Двенадцать слайдов для защиты Кейса 02 и отдельный текст выступления.

## Файлы

- `kosmo-deck.pptx` — презентация, 16:9, тёмно-зелёная тема, заметки докладчика
  вшиты в слайды.
- `kosmo-deck.pdf` — та же презентация для показа без PowerPoint.
- `renders/slide-01.png` … `slide-12.png` — снимки слайдов.
- `speaker-notes.docx` — текст защиты: хронометраж, что говорить на каждом
  слайде, цифры под рукой и ответы на вероятные вопросы.
- `build.mjs`, `theme.mjs`, `assets.mjs`, `data.mjs`, `script.mjs`,
  `notes.mjs`, `render.mjs` — сборка всего перечисленного.

## Шаблон

Шаблон собран нами и повторяет правила презентационного шаблона КРОК
(`design.croc.ru/presentations`): повторяющиеся элементы связывают слайды в одну
презентацию, слайд не перегружают информацией, кегль крупный, текста минимум,
на слайде остаётся воздух, второстепенное уходит в заметки, все элементы
выровнены друг относительно друга.

Палитра своя — тёмно-зелёная тема интерфейса из `app/static/styles.css`, чтобы
слайды и инструмент выглядели одинаково: фон `#08130E`, карточки `#0F1D17`,
акцент `#55B894`, латунь `#C39E53` для запаса и предупреждений. Шрифт
Montserrat, тот же, что в макете и интерфейсе.

Повторяющиеся элементы: зелёная полоса у края, два тонких кольца на фоне,
надзаголовок раздела, заголовок, одна строка подводки, подвал с номером слайда.
Сетка: 12 колонок, поля 0,62 дюйма, межколонник 0,2 дюйма.

Числа берутся из `results/` при сборке: `base.json`, `stress.json`,
`ranking_full.csv`, `alternatives.csv`, `portfolio_detail.csv`. Руками в слайдах
не набрана ни одна цифра, поэтому презентация не может разойтись с движком и
инструментом. Текст выступления лежит в `script.mjs` и попадает и в заметки
слайдов, и в `speaker-notes.docx`.

## Как пересобрать

```
npm i pptxgenjs sharp react react-dom react-icons qrcode docx
node docs/presentation/build.mjs     # kosmo-deck.pptx
node docs/presentation/notes.mjs     # speaker-notes.docx
node docs/presentation/render.mjs    # kosmo-deck.pdf и renders/*.png
```

Для `render.mjs` нужны LibreOffice и Python с `pymupdf`. Шрифт Montserrat
должен стоять в системе, иначе LibreOffice подставит свой и ширина строк в
PNG будет отличаться от настоящей.

## Правки

- Текст выступления и вопросы жюри — `script.mjs`.
- Цвета, сетка, типовые элементы — `theme.mjs`.
- Состав и вёрстка слайдов — `build.mjs`.
- Иконки (Tabler через `react-icons`) и QR-код — `assets.mjs`.

После любой правки пересобрать все три команды и закоммитить `pptx`, `pdf`,
`docx` и `renders/` вместе с исходниками.
