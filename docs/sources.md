Список литературы, на которую опирается `docs/management-note.docx`. Пункты 1–11 —
литература, предложенная организаторами (`cases/case02/README.organizers.md`, раздел 15).

Личность каждого источника проверена 12.09.2026: для пп. 1, 4, 6–11 — по Crossref
(`api.crossref.org/works/<DOI>`), для п. 5 — по согласованию содержимого DOI
(`doi.org`, CSL JSON), для пп. 2 и 3 — по странице издателя, для пп. 12–16 — по метаданным
и первым страницам присланных PDF. Совпали название, авторы, издание и год.

## Почему PDF не лежат в репозитории

Репозиторий публичный. Из присланных файлов п. 15 помечен «© 2024 Elsevier Ltd.
All rights reserved», у п. 16 лицензия OECD; выкладывать их в открытый доступ нельзя.
Пп. 12–14 распространяются по CC BY / CC BY-NC-ND и формально могли бы лежать рядом,
но чтобы не смешивать режимы, все PDF хранятся вне репозитория, а здесь остаются
проверяемые DOI. Все ссылки ведут на страницы издателей с полным текстом; пп. 6–11
открытого доступа.

Официальные отраслевые ссылки (Рослесхоз/ИСДМ-Рослесхоз, ESA по EO, Sentinel-1/2 и
InSAR, Росгидромет по «Арктике-М») и нормативные акты (44-ФЗ, 223-ФЗ, 224-ФЗ, 115-ФЗ,
89-ФЗ) с точными местами — в `docs/team/participant-2/source_register.md`.
