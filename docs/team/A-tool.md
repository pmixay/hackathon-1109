## Что строим

Streamlit-приложение поверх **неизменённого** `case_core.py`. Технологии на твой
выбор, но: без внешних API, без ключей, запуск одной командой, работает офлайн.

### Экраны

1. **Портфель.** Четыре выпадающих списка «лот» и четыре «режим» (A/B/C и D,
   если включён). Переключатель BASE/STRESS. Кнопка «Рассчитать».
2. **Показатели и ограничения.** Таблица показателей портфеля (c0, OPEX, vpub,
   cash, kcash, t_rep, readiness, resilience, scale, архетипы, группы,
   public core) и таблица ограничений: `условие | порог | факт | PASS/FAIL`.
   Все девять проверок из `check_constraints`. При FAIL — красная строка с
   текстом «нарушено: c0 1249.5 > 1180.0».
3. **Варианты.** «Сохранить как вариант» с именем. Таблица всех сохранённых:
   состав, режимы, показатели, статусы, сценарий. Один вариант можно посчитать
   в BASE и STRESS и увидеть обе строки рядом.
4. **Модель выбора.** Веса из `config/weights.json` (их даёт B), нормализация,
   итоговый балл по каждому варианту, ранжирование. Блок sensitivity: ±20 % по
   каждому весу и по vpub/cash, показывает, меняется ли лидер.
5. **Отсев.** Перебор всех 5670 комбинаций с фильтрами «проходит BASE»,
   «проходит STRESS», сортировка по любому столбцу. Код уже есть в
   `tools/case02_enumerate.py`.
6. **Режим D.** Читается из `config/custom_mode.json` (коэффициенты и
   обоснование). Если файла нет, D не показывается. Если `public_core = true`,
   рядом выводится текст-предупреждение о недискриминационном базовом слое.

### Экспорт

Кнопка «Экспорт результатов» пишет:
- `results/base.json` и `results/stress.json` — выбранный портфель:
  состав, режимы, все показатели, все проверки, timestamp, версия конфигов.
- `results/alternatives.csv` — все сохранённые варианты в обоих сценариях.
- `results/sensitivity.csv`.

Это **единственный источник цифр** для записки и слайдов. После заморозки в
17:00 файлы не меняются.

### Тесты (`pytest`)

- `apply_mode`: один лот × режим A даёт c0 × 1.05, cash = anchor × 1.0 + commercial × 0.25.
- Агрегация: сумма, среднее, счётчики архетипов и групп на известном портфеле.
- Границы: c0 = 1300 проходит BASE, 1180 проходит STRESS, 1180.01 не проходит;
  kcash = 0.6 проходит; t_rep = 0.63 проходит.
- Формулы B (модель выбора): результат на контрольном примере.
- «Исходные файлы не изменены»: хэш `lots.csv`, `access_modes.csv`,
  `case_config.json` совпадает с зафиксированным.

## Типовые потери баллов, которых ты избегаешь

- Смена портфеля требует правки кода → Т2 = 0–2.
