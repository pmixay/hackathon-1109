## Что ты делаешь

### 1. Потребности регионов и общественная ценность (раздел 1, П1)

По каждому лоту-кандидату, затем по четырём выбранным, цепочка:

`потребность → пользователь → сервис → действие пользователя → измеримый эффект → общественная ценность → KPI → источник данных для KPI`

Пример каркаса для FIRE: раннее обнаружение очагов в Сибири → региональная
лесная служба и МЧС → спутниковый мониторинг с оповещением → выезд на очаг
в первые часы → площадь пожара при ликвидации → сохранённый лес, здоровье
населения, расходы на тушение → KPI «медиана времени от обнаружения до
реагирования», источник — журнал лесной службы. Опора на отраслевые статьи
из раздела 16 README. Общественный эффект — отдельно от cash, без двойного
счёта, `vpub` упоминается как синтетическая шкала кейса.

### 2. Тиражирование (раздел 8, П8)

Три колонки: **тиражируемое ядро** (данные, алгоритмы, договорный шаблон,
стандарт KPI), **локальная адаптация** (пороги, сезонность, региональные
службы, языковая и организационная специфика), **передача опыта** (порядок
пилотов, кто ведёт реестр уроков, как обновляется стандарт после пилота).
Согласовать с индексом scale_1_5 и с межрегиональным соглашением от D.

### 3. Дорожная карта и KPI (раздел 9, П9)

Горизонт от C (например, 2027–2033). Таблица этапов: срок, результат,
ресурсы, ответственный, зависимости, критерий завершения. Этапы: подготовка
и закупка → пилот в одном регионе → оценка → тираж на 2–3 региона → полный
охват → пересмотр. Таблица KPI: показатель, что измеряет, источник данных,
способ проверки, периодичность.
