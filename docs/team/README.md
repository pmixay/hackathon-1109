## Правила для всех

1. Файлы организаторов (`lots.csv`, `access_modes.csv`, `case_config.json`,
   `case_core.py`) не редактируются. Своё — в `config/` с пометкой «допущение команды».
2. Цифры в текстах берутся только из `results/`. Не пересчитывать в уме, не
   держать вторую копию таблиц в Excel.
3. `vpub` не складывается с cash. `kcash` называется «покрытие OPEX денежными
   поступлениями», не «прибыль».
4. Записка, слайды и инструмент говорят одно и то же. Расхождение — дефект.
5. Каждый критерий рубрики имеет проверяемый артефакт. Устное объяснение баллов не даёт.
6. Вопрос, который блокирует работу, задаётся в общий чат сразу, не через час.
