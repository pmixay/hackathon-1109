# Проверка макета участника №5

Проверка приложенных экранов и ветки GitHub выполнена 12.09.2026.

Повторная проверка текущего `docs/mockup/kosmo-portfolio.html` подтверждает финальный состав и числа со скриншотов. Прежнее расхождение со старым all-A состоянием устранено после слияния работы №5 в общую ветку.

Текущий HTML показывает `FIRE-A + AGRI-B + TRANS-B + ENV-A` и итоговые значения `c0 = 1 140`, `OPEX = 313`, `vpub = 1 289`, `cash = 370,5`. Порядок на экране отличается от порядка аналитической карточки, но состав и режимы совпадают.

## Что должно быть в финальном экране

- Состав и режимы: `FIRE-A`, `ENV-A`, `AGRI-B`, `TRANS-B` (одинаковая подпись во всех экранах).
- Числа брать только из [`results/base.json`](https://github.com/pmixay/hackathon-1109/blob/main/results/base.json) и [`results/stress.json`](https://github.com/pmixay/hackathon-1109/blob/main/results/stress.json): `c0 = 1 140`, `OPEX = 313`, `cash = 370,5`, `K_cash = 1,184`, `vpub = 1 289`, запас по `c0` BASE/STRESS `160/40`.
- Для каждого лота явно показывать режим доступа A или B; для A — базовый публичный слой, для B — агрегированный якорный слой и авторизованную детальную услугу.
- Если интерфейс показывает плательщика: МЧС, Минприроды и Росавтодор подписывать как предполагаемых по консультации трекера; Минсельхоз - как гипотезу команды; Росавтодор относится только к дорожной части `TRANS`.
- При сбое показывать последний валидный слой, дату `source_updated_at`, флаг `stale`, пониженный `confidence` и ручной канал; не выдавать пропуск за новое событие.
- REST, журнал событий, два поставщика и контрольный набор обозначать как целевую архитектуру, пока они не реализованы в коде.

Проверка участника №2 касается содержания и согласованности макета. Функциональные тесты интерфейса остаются ответственностью №5.

Подробный снапшот с числами, источниками и правилами отображения передан отдельным файлом [`final_portfolio_snapshot.md`](final_portfolio_snapshot.md). Он нужен потому, что исходный ZIP №5 содержал только две CSV-карточки и не содержал `results/` или файлов организаторов.
