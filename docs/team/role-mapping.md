# Нумерация команды и буквы в репозитории

В чате команда использует нумерацию участников, а в исходных инструкциях репозитория сохранена буквенная раскладка A–E. Это два разных обозначения. Номер участника нельзя автоматически заменять буквой с тем же порядком.

## Рабочая нумерация команды

| Номер | Зона работы | Главный результат |
|---:|---|---|
| 1 | Координация и автор общей записки | Сборка разделов, единый текст и финальная сдача |
| 2 | Аналитик регионов и организации сервисов | Потребности, пользователи, плательщики, доступ, риски, тиражирование |
| 3 | Экономист | Портфель, cash/OPEX, BASE/STRESS и финансовая проверка |
| 4 | Расчётный движок и техническая архитектура | `src/`, `tests/`, `config/`, `results/` |
| 5 | Интерфейс и презентационные экраны | `app/`, `docs/mockup/`, карточки для интерфейса |

## Буквенная раскладка, уже записанная в `docs/team/`

| Буква | Что написано в репозитории |
|---|---|
| A | Разработчик, инструмент |
| B | Аналитик, модель выбора и альтернативы |
| C | Экономист, финансы и стресс |
| D | Юрист/закупщик, доступ, договоры и риски |
| E | Редактор и капитан, регионы, тиражирование, план и сборка |

Буквенная схема — исторический план репозитория. Материалы участника №2 из текущего рабочего распределения находятся в папке `docs/team/participant-2/` и не меняют инструкции A–E. Для финальных цифр всегда использовать `config/portfolio.json` и `results/`; для региональных карточек — `docs/team/participant-2/service_cards_full.csv`.

Финальный портфель команды: `FIRE-A + ENV-A + AGRI-B + TRANS-B`.
